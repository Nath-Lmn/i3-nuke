# ~ Never forget to I3 lock again ~
a list of all the commands requiered to nuke a Nix OS session when someone unfortunatly forgets to I3 lock 
(for epita students only)


![Funny picture :D](image%20github.png)


### how to use : 
copy the "prank.sh" file, then use the following commands : 
``` Bash
chmod +x prank.sh

./prank.sh                      # interactive menue ( easiest way )
./prank.sh rotate               # CLI
./prank.sh undo rotate          # undo the rotate 
./prank.sh wallpaper https://example.com/meme.png  # replace the wallpaper with the given picture ;)
./prank.sh all                  # full combo without risk
./prank.sh undo-all             # complete reset
```
